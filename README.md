## 1. 🌙 概述

CoreSplit 是一个**多层优化框架**。每个子系统都可通过统一配置界面独立启用、调整或禁用。模组通过设备分析和瓶颈检测自动适应主机硬件，为不同场景应用相应策略。

**✨ 核心设计原则：**

| 原则 | 说明 |
|------|------|
| 🛡️ 默认线程安全 | 所有共享状态使用 `volatile`、`Atomic*` 或并发集合 |
| ⛓️ 处处有界 | 线程池队列、缓存和批处理器均强制执行容量限制，防止 OOM |
| 🧵 主线程非阻塞 | 繁重工作在专用后台线程上运行 |
| 🎭 面向接口编程 | 字段声明优先使用 `Map`/`Queue` 而非具体实现 |

## 2. 🎀 核心模块

### 2.1 🧠 AI 优化

在不破坏原版行为的前提下，降低实体 AI 运算的 CPU 开销。

| 特性 | 说明 |
|------|------|
| **实体 AI 节流** | 基于距离的 AI 计算桶（近/中/远/屏外）。远处实体 AI 频率降低；屏外实体可完全暂停。 |
| **路径缓存** | LRU + TTL 缓存，以实体类型和区块坐标为键。容量溢出时淘汰最旧条目。 |
| **共享路径注册表** | 同区域同类型实体复用共享路径，避免重复 A\* 计算。 |
| **空间索引** | 按距离对实体分桶，实现 O(1) 节流分类。 |
| **全局倍率** | 范围 `[0, 1]` 的标量，乘以 AI 频率——设为 `0` 可暂停所有 AI。 |

> 💡 节流器注入到 `Mob.serverAiStep()`（而非 `tick()`），物理、移动和插值继续正常运行，仅节流目标/大脑/控制相关计算。

### 2.2 🗺️ 区块引擎

并行化区块生成和异步 I/O。

| 特性 | 说明 |
|------|------|
| **并行区块生成器** | 多线程地形噪声生成，使用优先级任务调度器。 |
| **异步区块 I/O** | 非阻塞区块磁盘读写，跟踪进行中操作。 |
| **区块任务调度器** | 支持取消和活跃任务跟踪的优先级队列。 |
| **实体过滤器** | 基于范围的实体查询，供区块引擎和 AI 节流器使用。 |

### 2.3 💥 爆炸优化

防止爆炸导致帧率骤降和粒子风暴。

| 特性 | 说明 |
|------|------|
| **爆炸批处理器** | 有界 `PriorityBlockingQueue`，每帧每 Tick 批量处理爆炸，近者优先。 |
| **异步爆炸处理器** | 将爆炸计算卸载到主线程之外。 |
| **方块影响跳过** | 跳过超出可配置 3D 距离阈值的方块冲击检测。 |
| **粒子限制器** | 每次爆炸粒子数限制为 LOW(8) / MEDIUM(32) / HIGH(128)。 |

### 2.4 💾 内存管理

最激进的子系统——直接解决着色器负载下的高内存使用问题。

| 特性 | 说明 |
|------|------|
| **ByteBuffer 池** | 按 2 的幂次分桶复用 `ByteBuffer` 实例，消除 GC 压力。每桶上限 32，可在运行时切换。 |
| **实体数据池** | 对象池，工厂 + 重置器模式，线程安全。 |
| **资源驱逐器** | 定期缓存驱逐，可配置间隔和动态纹理缓存目标大小。 |
| **堆整理器** | 低优先级后台线程运行，避免主线程停顿。 |
| **动态内存优化器** | 在 `CoreSplit-MemoryCleaner` 线程上触发清理——绝不调用 `System.gc()` 或 `Thread.sleep()`。 |
| **实体数据卸载器** | 卸载超出可配置距离的实体数据。 |
| **着色器内存优化器** | 仅 Iris 着色器启用时生效：纹理缓存减半，每 30s 驱逐，禁用时恢复。 |

### 2.5 ⚡ GPU 加速

可插拔的 GPU 计算后端，带自动健康监控和 CPU 回退。

| 后端 | 状态 | 说明 |
|------|------|------|
| **OpenGL** | 默认 | 始终可用 |
| **Vulkan** | 实验性 | 反射加载 |
| **OpenCL** | 实验性 | 反射加载 |
| **CUDA** | 实验性 | 需 NVIDIA GPU + CUDA 工具包 |
| **CPU 回退** | 备选 | 无 GPU 或后端降级时使用 |

> ⚠️ 后端**互斥**——启用一个会自动禁用其他。注册表监控后端健康，以下情况会回退 CPU：
> - 🔻 持续慢任务（> 100ms）
> - 💔 连续 3 次以上失败
> - 📉 成功率低于 80%

### 2.6 🎨 渲染限制器

| 特性 | 说明 |
|------|------|
| **实体渲染限制器** | 限制每帧渲染实体数，Iris/Sodium 下有更严格限制。 |
| **视锥体裁剪器** | 剔除视锥体外的物品渲染。 |
| **物品渲染优化器** | 可调节的物品渲染距离和频率。 |
| **GPU 监控器** | 跟踪 GPU 任务延迟和成功率。 |

### 2.7 🎚️ 性能调节器

根据实时 FPS、MSPT 和 CPU 使用率动态调整渲染质量。

- ⭐ **质量等级** 0–5，单调过渡
- 🧮 **帧时间值** 钳制，防止 NaN/Inf 破坏 FPS 计算
- 🚀 **高 FPS**（> 200）：调整间隔延至 5s，需连续趋势检测
- 🌈 **着色器下**：支持强制垂直同步和 GPU 过载检测

### 2.8 🌟 着色器兼容性

与 Iris 和 Sodium 深度集成——仅在这些模组加载时启用。

| 特性 | 说明 |
|------|------|
| **着色器性能优化器** | 着色器启用时：限制渲染距离、强制垂直同步、减少粒子/实体。禁用时自动恢复。 |
| **着色器内存优化器** | 参见[内存管理](#24-内存管理) |
| **兼容性协调器** | 中央协调器，限制渲染距离并协调所有着色器感知模块。 |
| **Iris/Sodium 配置 Schema** | 解析配置文件，缓存远程 Schema 获取（双开关、异步、限速）。 |
| **反射缓存** | 用 `ConcurrentHashMap` 缓存 Sodium 字段反射，避免重复调用。 |
| **冲突管理器** | 通过 `FabricLoader.getInstance().isModLoaded()` 检测冲突。 |

### 2.9 🧸 模型与纹理系统

| 组件 | 说明 |
|------|------|
| **动画控制器 / 状态管理器 / 优化器** | 管理动画变量、LOD 和插值 |
| **JEM 文件解析器** | 解析 OptiFine 格式 JEM/JPM 实体模型 |
| **玩家模型处理器** | 玩家模型骨骼变换管理 |
| **方块实体模型适配器** | 管理方块实体渲染状态 |
| **纹理缓存** | LRU 缓存，可配置最大大小 |
| **自发光渲染器** | 处理自发光纹理数据 |
| **玩家皮肤增强器** | 皮肤透明度钳制处理 |
| **OptiFine 属性解析器** | 解析生物群系/动画/皮肤属性 |

### 2.10 🎵 实体音效系统

| 组件 | 说明 |
|------|------|
| **实体音效系统** | 完整播放→淡出→停止生命周期 |
| **音效变体管理器** | 根据实体纹理和概率条件切换音效变体 |
| **音效驱动视觉管理器** | 应用/还原音效事件相关的视觉变化 |
| **音效动画集成器** | 淡入/淡出、状态转换和 `playsound` 指令处理 |

### 2.11 📊 监控与诊断

| 工具 | 说明 |
|------|------|
| **性能监控器** | 实时 FPS、MSPT、帧时间和 CPU 指标 |
| **瓶颈分析器** | 分类：`NONE` / `CPU_BOUND` / `GPU_BOUND` / `ENTITY_BOUND` / `MEMORY_BOUND` |
| **设备分析** | 检测硬件等级、CPU 核心数和内存，推荐预设 |
| **客户端/服务器指标缓存** | 有界缓存（256–1024 条目）防止泄漏 |
| **调试覆盖层** | F3 覆盖层，含 CoreSplit 调试条目、快捷键和 GPU 瓶颈警报 |

### 2.12 ⏰ 调度器

| 组件 | 说明 |
|------|------|
| **任务调度器** | 可配置线程池（核心数 × 倍率，限制 1–4×），优雅关闭 |
| **优先级任务调度器** | 有界队列 + `CallerRunsPolicy`，`finally` 中计数完成任务 |
| **配置文件管理器** | 保存/加载/激活命名配置，防重名 |
| **资源监控器** | 跟踪系统资源使用情况 |

## 3. ⚙️ 配置

CoreSplit 配备由 **YACL** 驱动的统一配置 UI，可通过 **ModMenu** 访问。配置文件存储为 `coresplit_client.toml`。

| 分类 | 包含项 |
|------|--------|
| **引擎** | 核心优化开关和模式 |
| **覆盖层** | 调试 HUD 和快捷键 |
| **性能** | 调节器、FPS 目标和质量等级 |
| **兼容性** | Iris/Sodium 深度兼容开关和远程 Schema 获取 |
| **调度器** | 线程池大小 |
| **渲染** | 实体渲染限制、视锥体裁剪、物品渲染 |
| **GPU** | 后端选择、CUDA 开关、健康监控阈值 |
| **着色器优化**（10 项） | 主开关、强制垂直同步、减少粒子、减少实体、限制渲染距离、激进内存释放、阴影距离余量、最大渲染距离上限、粒子渲染距离、实体倍率 |
| **内存管理**（6 项） | 主开关、ByteBuffer 池开关、纹理缓存限制、实体数据池大小、缓存驱逐间隔、激进驱逐阈值 |

> 📝 所有 setter 执行三个操作：更新字段 → 运行时应用 → `save()` 持久化。每个数值输入均强制执行范围验证。

## 5. 📦 安装

1. 🧱 安装 **Fabric Loader** 0.16.0 或更新版本
2. 🔧 安装 **Fabric API**
3. 🎒 将 `coresplit-2.5.0.jar` 放入 `mods/` 文件夹
4. 💜（推荐）安装 **ModMenu** 以访问配置界面
5. 🌌（可选）安装 **Iris** 和 **Sodium** 以启用着色器感知优化
6. ▶️ 启动游戏——CoreSplit 会自动分析你的硬件并应用推荐预设
